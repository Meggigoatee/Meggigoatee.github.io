## 프로젝트 목적

완도 AI 아바타 생성 프로그램은 관람객이 키오스크에서 출력 디자인과 캐릭터 유형을 고르고 얼굴을 촬영하면, AI로 생성된 후보 중 하나를 선택해 아바타 결과물을 만드는 Electron 애플리케이션입니다. 완성한 결과는 현장에서 인쇄하는 동시에 QR 코드로 개인 기기에 내려받을 수 있도록 한 번의 체험 흐름으로 연결되어 있습니다.

소스에서 확인되는 사용자 흐름은 `프레임 선택 → 캐릭터 선택 → 얼굴 촬영 → AI 이미지 생성 → 후보 선택 → 배경 제거와 얼굴 편집 → 프레임 합성 → 인쇄·QR 전달`입니다. 일정 시간 입력이 없으면 시작 화면으로 돌아가며, 완료 화면에서도 잠시 후 상태를 초기화해 다음 관람객의 체험을 준비합니다.

## 담당 범위

본인의 정확한 담당 범위, 팀 구성, 작업 기간과 기획·디자인 참여 여부는 확인이 필요합니다.

저장소에서 확인되는 구현 범위는 다음과 같습니다.

- Electron 메인·프리로드·Vue 렌더러 사이의 이미지 생성, 저장, 인쇄와 공유 IPC 구성
- 카메라 촬영과 MediaPipe 얼굴 검출을 이용한 촬영 유효성 검사 및 얼굴 영역 크롭
- AI 이미지 생성 요청, 진행 상태 확인과 생성 후보 선택 흐름
- 선택 결과의 투명 배경 처리와 얼굴 좌표를 이용한 아바타 편집
- OffscreenCanvas 프레임 합성, Sharp 기반 출력 이미지 보정과 Windows 인쇄 연결
- 만료되는 공유 링크와 QR 코드를 이용한 모바일 결과물 전달

## 기술 스택

- 데스크탑 런타임과 화면: Electron, Vue 3, TypeScript, Pinia
- 얼굴 처리: MediaPipe Tasks Vision, OffscreenCanvas, 외부 컷아웃 서비스 연동
- 이미지 출력: Canvas, Sharp, Electron `nativeImage`
- 결과 전달: QR Code, 로컬 임시 공유 서버와 터널 프로세스
- 패키징: electron-vite, electron-builder, Windows NSIS·portable 설정

## 핵심 구현

### 1. 촬영 단계의 얼굴 검출과 크롭

카메라 영상을 좌우 반전해 안내 화면과 같은 방향으로 보여주고, 5초 카운트다운 뒤 프레임을 PNG로 캡처합니다. MediaPipe Tasks Vision의 로컬 BlazeFace 모델로 얼굴을 검출해 얼굴이 없거나 검출 영역이 너무 작으면 다음 단계로 넘기지 않습니다. 유효한 얼굴은 바운딩 박스를 중심으로 주변 영역을 넓혀 OffscreenCanvas에서 크롭한 뒤 AI 이미지 생성 입력으로 사용합니다.

MediaPipe 래퍼에는 Face Landmarker와 다중 클래스 인물 세그멘터도 로컬 모델로 초기화되어 있지만, 조사한 현재 화면 흐름에서는 얼굴 검출 메서드만 실제 호출됩니다. 따라서 랜드마크와 배경 분리 전체를 MediaPipe가 수행한다고 표현하지 않았습니다.

### 2. AI 생성 결과 선택과 인물 분리

촬영 이미지를 이미지 생성 파이프라인에 전달하고 작업 상태를 주기적으로 확인한 뒤, 완료된 후보 이미지를 내려받아 선택 화면에 표시합니다. 관람객이 한 후보를 고르면 컷아웃 요청에 투명 배경, 얼굴 분석과 PNG 출력을 지정합니다. 응답으로 받은 투명 배경 이미지와 68점 얼굴 좌표를 함께 보관하고, 실패 시 한 차례 지연 재시도 후 오류 화면으로 연결합니다.

이 단계의 배경 제거와 얼굴 좌표는 MediaPipe가 아니라 별도 컷아웃 서비스의 응답을 사용합니다. 서비스 주소, 인증 정보와 생성 프롬프트는 공개 콘텐츠에서 제외했습니다.

### 3. 얼굴 좌표를 활용한 이미지 합성과 프레임 배치

투명 배경 이미지를 OffscreenCanvas에 올리고 얼굴 좌표의 턱 끝을 기준으로 아래쪽을 정리합니다. 알파 채널을 순회해 실제 픽셀이 있는 범위만 다시 크롭하고 PNG Blob으로 저장합니다. 이후 선택한 캐릭터와 프레임 조합을 불러와, 프레임마다 정의된 기준점에 얼굴 이미지의 아래쪽 중앙을 맞춰 최종 출력 이미지를 합성합니다.

이처럼 인물 분리 결과, 랜드마크 좌표, 프레임별 배치 기준을 연속된 처리 단계로 나눠 얼굴 크기와 위치가 다른 결과도 같은 출력 레이아웃에 맞추도록 구성했습니다.

### 4. Sharp 출력·인쇄와 QR 결과 전달

완성 이미지는 Electron 메인 프로세스로 전달합니다. Sharp로 이미지 메타데이터를 확인하고 인쇄용 사진의 방향에 따라 회전과 300 DPI 메타데이터를 적용한 뒤 PNG로 저장합니다. 저장된 경로는 별도 PowerShell 인쇄 스크립트에 전달되어 Windows 기본 프린터 출력으로 이어집니다. 아바타 단독 결과도 유형을 구분해 지정된 저장소에 별도로 내보냅니다.

동시에 최종 이미지를 메모리 기반 임시 공유 저장소에 등록하고, 로컬 서버를 외부에서 접근할 수 있는 임시 터널과 연결해 다운로드 URL을 만듭니다. 이 URL을 높은 오류 복원 수준의 QR 이미지로 렌더링하며, 공유 항목과 다운로드 페이지는 3분 후 만료되도록 구성되어 있습니다. 결과 파일을 장기 공개 주소에 두지 않고 체험 직후 전달하는 방식입니다.

## 핵심 판단과 결과

코드에서 확인되는 결과는 촬영, AI 후보 선택, 인물 편집, 프레임 합성, 실물 인쇄와 QR 다운로드까지 이어지는 키오스크 흐름입니다. 특히 얼굴 검출은 로컬 MediaPipe 모델, 배경 제거와 좌표 분석은 별도 서비스, 고해상도 출력 보정과 인쇄는 Electron 메인 프로세스로 책임을 나눈 점이 특징입니다.

테스트 자동화는 저장소에서 확인되지 않았으며, 빌드 스크립트에는 TypeScript 검사와 Windows 설치·portable 패키징이 포함되어 있습니다. 실제 납품·운영 상태, 프린터와 카메라 호환 범위, 생성 성공률, 처리 시간과 관람객 반응은 확인이 필요합니다. 대표 기술 판단은 `문제 → 대안 소개 → 결정 이유 → 결과` 순서로 추가 확인합니다.
