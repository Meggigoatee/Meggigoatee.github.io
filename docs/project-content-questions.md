# 프로젝트 콘텐츠 확인 질문

소스에서 확인할 수 없는 정보를 추측하지 않기 위해 아래 항목은 사용자 확인 후 공개 콘텐츠에 반영한다. 여러 프로젝트에 같은 답이 적용되면 한 번만 답해도 된다.

## 공통 질문

1. 각 프로젝트의 작업 기간은 언제인가?
2. 개인 프로젝트인지 팀 프로젝트인지, 팀이라면 대략적인 구성은 어떠했는가?
3. 본인의 정확한 담당 범위는 무엇인가?
4. 기획과 UI·그래픽 디자인에 참여했는가?
5. 가장 어려웠던 문제와 직접 선택한 해결 방법은 무엇인가?
6. 운영, 납품, 출시 또는 전시 상태는 어떻게 되는가?
7. 공개 가능한 프로젝트명·클라이언트명·화면 범위는 어디까지인가?
8. 수치로 공개할 수 있는 성능이나 운영 결과가 있는가?
9. 포트폴리오에서 강조할 대표 기술 의사결정 하나를 아래 형식으로 설명할 수 있는가?
   - 문제: 어떤 문제가 있었는가?
   - 대안 소개: 어떤 선택지들을 검토했는가?
   - 결정 이유: 무엇을 선택했고 왜 선택했는가?
   - 결과: 선택 이후 무엇이 달라졌는가? 정량 수치가 없다면 확인 가능한 변화는 무엇인가?

## 프로젝트별 확인 포인트

### i-syncPlayer System

- 확인 완료
- 대표 이미지와 실제 실행 화면은 추후 추가

### Icecream Table

- 확인 완료
- 공개 명칭은 `미디어테이블`
- 공식 오픈 전이므로 실제 화면과 내부 프로젝트명은 공개하지 않음

### 황금마패의 길

- 확인 완료
- 공개 명칭은 `황금마패의 길`
- 프로젝트명과 화면 모두 공개 가능

### Tobomi

- 확인 완료
- 프로젝트명과 화면은 공개 가능, 저장소는 비공개
- 2026년 8월 25일 Windows 데모 출시 예정, macOS 지원 예정

### 완도 AI 아바타 생성 프로그램

- 외부 이미지 생성·컷아웃 계층과 키오스크 앱 중 담당 영역
- 인쇄·QR 전달 흐름의 실제 현장 운영 여부
- 공개 가능한 처리 시간이나 출력 규격

### B the B LIVE WALL

- 외부 API 연동, 카드 연출, 운영 설정과 패키징 중 담당 영역
- 라이브 월의 운영·납품 상태와 공개 가능한 갱신 규모

### 정읍 방문자센터 마을 만들기

- 객체 감지 입력, 장면 생성, 이동·배치 로직과 패키징 중 담당 영역
- 실제 전시 운영 여부
- 베지어 이동 모듈을 현재 기능으로 소개할지 후속 확장 실험으로 소개할지
